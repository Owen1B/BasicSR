# Legacy Datasets

This folder contains archived dataset implementations.

- They are not imported by `prime.bootstrap.register_all()`.
- They are not part of the active converged mainline.
- Keep for historical reference/reproduction only.

Archived modules include:
- `nema_single_projection_dataset.py`
- `spect_dat_paired_dataset.py` (old AP/2D mainline)
- `spect60view_volume_dataset.py` (old volume/3D mainline)
- `spect60view_dataset.py` (old per-view 2D pipeline)
- `neighbor2neighbor_dataset.py`
- `noise2void_dataset.py`
- `self2self_dataset.py`
- `noiser2noise_dataset.py`
